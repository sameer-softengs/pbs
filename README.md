# PBS

A full-stack application organized into separate client and server components, with an open-source license included in the repository.

## Architecture

- `client/` — frontend application
- `server/` — backend services and business logic

## Getting Started

```bash
git clone https://github.com/sameer-softengs/pbs.git
cd pbs
```

Install dependencies and start the client and server using the instructions and package configuration within each directory.

## Development

Run the frontend and backend independently during development unless the repository provides a combined start command. Configure environment variables locally and never commit credentials.
